ReturnObject の設定項目

項目型説明
PoolsGameObject[]非表示にする対象が登録された VRCObjectPool のGameObject、またはそれを子に持つ親GameObject
ReferenceReturnObject別の ReturnObject に設定された Pools を共有するための参照
LayerintReturnを受け付けるGameObjectのレイヤー番号
既定値は 13（Pickup）
Audio SourceAudioSourceReturn成功時に使用する音源
未指定の場合は再生しない
Audio ClipAudioClipReturn成功時に再生するクリップ
未指定の場合は Audio Source に設定されたクリップを使用する
どちらも未指定の場合は再生しない

Pools​

登録したGameObject自身と、その子階層から VRCObjectPool を検索します。複数の VRCObjectPool オブジェクトを空の親GameObject以下にまとめておくと、一括で登録でき、以降のメンテナンスもしやすくなります。

Reference​

Reference に別の ReturnObject を設定すると、その ReturnObject の Pools も検索対象になります。現在の Pools と参照先の Pools に同じGameObjectが登録されている場合、そのGameObjectは重複して検索されません。

Pools を空にする場合、Reference の設定が必要です。

Layer​

トリガーに入ったColliderを持つGameObjectのレイヤー番号が、この値と一致する場合だけReturn処理を行います。Object Spawn System（標準版）では、そのGameObjectが VRCObjectPool へ登録されている必要があります。
