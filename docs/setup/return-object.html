Returnトリガーを作る

Returnトリガーへ表示中のオブジェクトを入れると、PickupをDropしたあと、そのオブジェクトを非表示にします。

設定手順​

  1. HierarchyにReturnトリガー用のGameObjectを追加する
  2. ReturnObject コンポーネントを追加する
  3. Colliderを追加し、Is Trigger を有効にする
  4. ReturnObject の Pools に、非表示にする対象が登録された VRCObjectPool のGameObjectを登録する
  5. Layer を、Return対象のGameObjectのレイヤー番号にする

既定のLayerは 13 で、VRChatのPickupレイヤーを示します。

Layer 値の設定について

Layer には、Return対象のGameObjectと同じレイヤー番号を設定します。Object Spawn Systemと関係のないPickupが同じレイヤーに設定されている場合、Returnトリガーへ入ったときに強制的にDropされる可能性があります。

意図しない反応を防ぐための専用レイヤーの作成方法は、PickupをSpawn対応にする をご覧ください。

複数のPoolを登録する​

Pools には、次のどちらも登録できます。

  • VRCObjectPool コンポーネントがあるGameObject
  • 複数の VRCObjectPool を子に持つ親GameObject

料理や飲み物など、種類ごとに VRCObjectPool を分ける場合は、空の親GameObject以下にまとめます。

ObjectSpawnPools
├─ FoodPool
├─ DrinkPool
└─ DessertPool

この例では、ObjectSpawnPools を Pools へ登録すると、その子階層にあるすべての VRCObjectPool がReturn対象になります。

別のReturnObjectと設定を共有する​

複数のReturnトリガーで同じPool設定を使いたい場合は、Reference へ設定済みの ReturnObject を登録します。

複数のReturnトリガーから、同じPool設定を共有できます。

Return 対象

Object Spawn System（標準版）では、トリガーに入るGameObjectそのものが VRCObjectPool へ登録されている必要があります。

動作確認​

  1. Spawnスイッチからオブジェクトを表示する
  2. 表示したオブジェクトをReturnトリガーへ入れる
  3. PickupがDropされ、オブジェクトが非表示になることを確認する

各項目の詳細は Return Objectの設定項目 をご覧ください。
